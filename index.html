Pack hors ligne

L'interface, les données et un lanceur : rien ne sort de ta machine.

1

Choisis ton pack

Un pack par système, avec le bon lanceur inclus.

WindowsZIP · start.bat macOSZIP · start.sh LinuxZIP · start.sh

Ou clone le dépôt avec Git :

Dépôt GitHub 
git clone https://github.com/chpalitom09-bot/LocalLLM.git
2

Lance le serveur local

Il faut un serveur : ouvrir index.html en double-clic ne charge pas les JSON. Python 3 suffit.

Windows : double-clic sur start.bat, ou

py -m http.server 8080

macOS / Linux :

sh start.sh
# ou : python3 -m http.server 8080

Sans Python : npx serve .

3

Ouvre l'interface

http://localhost:8080
4

Fais tourner un modèle

Avec llama.cpp, télécharge et sers un GGUF choisi dans le catalogue :

llama-server -hf unsloth/Qwen3-8B-GGUF:Q4_K_M

Avec Ollama :

ollama run qwen3:8b

Données seules

Pour réutiliser le catalogue dans tes propres outils.

models.json hardware.json

Impossible de charger models.json et hardware.json. Lance la page depuis un serveur (voir « Pack hors ligne »), pas en double-cliquant sur le fichier.
